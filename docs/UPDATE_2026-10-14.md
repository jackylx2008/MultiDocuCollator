# 2026-10-14 应用图标与 Windows EXE 交付更新

## 图标

应用图标改为“两份联系单归集为一张汇总表”的设计，对应项目的资料扫描与汇总功能。
可编辑源文件为 `assets/serve_summary_icon.svg`；运行 `python assets/build_icon.py`
可重新生成 `assets/serve_summary_icon.png` 和 `assets/serve_summary.ico`。
图标生成需要 CairoSVG 和 Pillow。旧的位图源稿已移除。

源码运行时，控制窗口会从 `assets/serve_summary.ico` 读取图标；打包后的 EXE
使用内嵌图标及随程序打包的 ICO。

## EXE 交付目录

在项目根目录运行：

```powershell
.\build_serve_summary_exe.ps1
```

脚本将单文件 EXE 构建到 `build/delivery/酒店需求工作联系单汇总.exe`，并将
`config.yaml` 与 `common.env.example` 复制到同一目录。项目根目录不再作为
EXE 输出位置。程序会从 EXE 所在目录读取 `config.yaml`、`.env` 或 `common.env`；
需要本机专用设置时，在交付目录创建 `.env` 或 `common.env`。

`build/` 和 `*.exe` 均由 Git 忽略。Git 同步包含图标源文件、生成图标、脚本与文档，
不包含 EXE、私有环境文件或运行日志。仅通过 Git 获取项目时，需要在 Windows 本地构建；
也可以单独复制整个交付目录。

## 验证

- Windows PyInstaller 构建成功，交付目录包含 EXE、`config.yaml` 和 `common.env.example`。
- 从 EXE 提取的图标与新设计一致；ICO 包含 16、24、32、48、64、128、256 像素规格。
- 项目根目录没有 EXE；交付目录中的 `config.yaml` 与项目配置文件内容一致。
