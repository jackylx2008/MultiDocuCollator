# 2026-09-25 汇总页人工状态筛选更新

## 更新内容

酒店需求工作联系单汇总 HTML 的以下两列表头新增筛选器：

- 是否需要变更
- 现场是否已经完成

每个筛选器均提供“全部、是、否”三个选项。筛选结果会即时刷新，并可与已有的
关键词搜索、专业、需求单打印状态及“状态 / 核对”筛选条件组合使用。

逐行的“是 / 否”人工编辑方式、保存接口和 JSON 字段没有变化，不需要迁移已有数据。

## 使用方法

重新生成汇总文件：

```bash
python build_archive.py
```

也可以启动本地服务；服务启动时会先刷新 JSON 和 HTML：

```bash
python serve_summary.py
```

打开生成的 `酒店需求工作联系单汇总.html`，在对应列标题下选择筛选值即可。选择
“全部”可清除该列条件。
