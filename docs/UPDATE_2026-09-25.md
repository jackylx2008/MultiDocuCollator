# 2026-09-25 汇总页人工状态筛选更新

## 更新内容

酒店需求工作联系单汇总 HTML 的以下两列表头新增筛选器：

- 是否需要变更
- 现场是否已经完成

每个筛选器均提供“全部、是、否”三个选项。筛选结果会即时刷新，并可与已有的
关键词搜索、专业、需求单打印状态及“状态 / 核对”筛选条件组合使用。

逐行的“是 / 否”人工编辑方式、保存接口和 JSON 字段没有变化，不需要迁移已有数据。

## 使用方法

重新生成汇总文件：

```bash
python build_archive.py
```

也可以启动本地服务；服务启动时会先刷新 JSON 和 HTML：

```bash
python serve_summary.py
```

打开生成的 `酒店需求工作联系单汇总.html`，在对应列标题下选择筛选值即可。选择
“全部”可清除该列条件。

## 同名 PDF 首页替换

既有记录点击“保存内容”并重新生成 Word/PDF 时，如果资料目录中已有同名 PDF，
系统会在事务临时目录生成新版单页 PDF，并组合为“新版第一页 + 原文件第二页起”。
组合文件通过格式和页数校验后才替换正式 PDF，因此原文件中的附图或附件页不会被
新版单页 PDF 整体覆盖。若生成、组合或后续 JSON/HTML 刷新失败，事务会恢复原 Word、
原 PDF 和原目录。

该功能使用 `pypdf`，更新代码后需执行：

```bash
python -m pip install -r requirements.txt
```

## Windows EXE 与应用图标

新增酒店建筑、文档和完成标记组合的应用图标，并提供 `build_serve_summary_exe.ps1`
将 `serve_summary.py` 打包为单文件 Windows 程序。EXE 不再显示黑色控制台，改为
提供带“打开汇总页面”和“停止服务”按钮的小型控制窗口；关闭窗口时会停止 HTTP 服务
并释放端口。冻结后的程序从 EXE 所在目录读取 `config.yaml`、`.env` 或 `common.env`，
日志也写入该目录的 `logs/`。

推荐使用独立构建环境：

```powershell
python -m venv .build-venv
.\.build-venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\build_serve_summary_exe.ps1
```

输出文件为项目根目录下的 `酒店需求工作联系单汇总.exe`。该本地产物由 `.gitignore`
排除，不提交到版本库；图标源文件、ICO、构建脚本和依赖声明进入版本管理。
