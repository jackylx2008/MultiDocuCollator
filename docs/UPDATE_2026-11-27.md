# 2026-11-27：酒店需求单 PDF 的 Bluebeam A4 转换

酒店需求单汇总页新增 PDF 转换入口：右键任一 PDF 可选择“打印成A4”；工具栏提供“批量转换酒店需求单PDF”，批量范围仅为资料记录中的酒店需求单 PDF（`issued_pdf`），不包含扫描件、附图或附件。转换先写入同目录临时文件，验证 PDF 后将旧件备份为 `.pdf.bak`（同名备份会覆盖），再替换原文件。

JSON 在每个 PDF 文件项记录 Bluebeam A4 转换标记和转换后文件哈希。HTML 对已标记 PDF 显示绿色底色、未标记 PDF 显示橙黄色；重新扫描后，仅当文件哈希仍匹配时保留已打印标记。

已在 Bluebeam Revu x64 eXtreme 20.2.70 上核对本机行为：ScriptEngine 的 `PrintToFile` 将 PDF 页面通过 Bluebeam PDF 驱动重印为 PostScript；随后由 `ps2pdf` 转为 PDF。输出按 Bluebeam 打印机当前默认纸型生成，并在替换前逐页校验 A4 尺寸。酒店需求单的 101 份 PDF 均已实际转换并逐页核验，原件 `.pdf.bak` 备份齐全，JSON 与 HTML 均标记为已转换。

日志中连续的归档扫描来自旧实现对每份 PDF 都调用一次全库刷新；已改为单文件转换只更新对应 JSON 文件项，批量过程不逐份重扫。旧版 App 重新扫描时会丢失 PDF 自定义状态，因此已按当前代码重新构建 App 并替换旧文件，旧版另存为 `酒店需求工作联系单汇总v2.exe.20261127.bak`。重新扫描验证后，101/101 个 PDF 状态仍有效。

## HTML 主题链接和编辑方式

酒店需求单 HTML 中，点击已有记录的主题会直接打开该条对应的资料目录。主题修改入口统一放在需求内容编辑窗口中，窗口内可同时修改主题和具体需求正文并保存。新增记录时，点击主题框或需求内容框都会打开同一个编辑窗口，填写结果一并回填到新增行。
