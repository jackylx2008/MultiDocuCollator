# 2026-11-26：HTML 汇总页主显示器最大化

通过桌面应用启动酒店需求单或主体工作联系单 HTML 汇总页时，Windows 会在页面打开后定位本次新建的浏览器窗口，将其移至系统主显示器的可用工作区并最大化。窗口通过页面标题标记识别，避免误移动用户已有的汇总窗口。

窗口定位有等待上限。超时或无法读取主显示器工作区时，会记录警告，已打开的页面仍可继续使用。macOS 和 Linux 继续使用系统默认浏览器打开页面。

实现位于 `src/multidocu_collator/flows/summary_server_flow.py`，遵循 [HTML 页面启动与显示通用要求](HTML_PAGE_REQUIREMENTS.md)。
